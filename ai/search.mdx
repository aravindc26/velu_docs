---
title: "Search"
description: "Full-text search across your docs, opened with the search box or ⌘K."
---

Every site has full-text search, powered by [Pagefind](https://pagefind.app).
Readers open it from the search box in the header or with the keyboard shortcut
⌘K (Ctrl+K on Windows and Linux), then type to find matching pages.

Search is on by default. There's no configuration to enable it.

## Local preview

The search index is built at deploy time. In `velu dev` the search box appears,
but it tells you that full-text search isn't available until the site is deployed.
To try search over your content, publish the site — see
[Publishing](/deploy/publishing).
