<Update label="September 2026" description="0.2.38" tags={["Fixed"]}>
  ### Fixed

  - Horizontal trackpad scroll no longer moves sticky chrome (header, sidebars)
  - Site footer optical center matches the article column (accounts for the left
    nav, not the full viewport)
  - Left nav stays full height beside the footer, with an always-visible
    scrollbar and no edge fade arrows
</Update>

<Update label="September 2026" description="0.2.37" tags={["Added"]}>
  ### Added

  - [Migrate from Mintlify](/docs/migrate-from-mintlify) — `velu migrate mintlify`
    converts a local Mintlify project into a new Velu directory (**beta**)
  - [Vepa theme](/docs/configuration/themes#vepa-preset) — set `"theme": "vepa"`
    for denser docs chrome; Mintlify `sequoia` maps to `vepa` on migrate
</Update>

<Update label="September 2026" description="0.2.36" tags={["Added"]}>
  ### Added

  - [Page modes](/docs/writing/page-modes) — set `mode` in frontmatter to `default`,
    `wide`, `custom`, `frame`, `center`, or `assistant`
  - Custom CSS and JS from the project root are included on every page
</Update>
