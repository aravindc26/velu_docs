<Update label="September 2026" description="Workflow run CSV export" tags={["Added"]}>
  ### Added

  - [Export workflow run history to CSV](/docs/dashboard/workflows#export-run-history-to-csv) —
    click **Export CSV** on the Workflows page to download all runs matching the
    current status filter. The file includes run ID, workflow name, status,
    trigger details, timestamps, run summary, and a link to the output pull
    request.
</Update>

<Update label="September 2026" description="Personalization" tags={["Added"]}>
  ### Added

  - [Personalized content](/docs/writing/personalization) — shared session on
    public sites, MDX `{user}` fields, Try It prefills, and OpenAPI `x-velu`
    group filtering. Value plan. Mutually exclusive with private authentication.
</Update>

<Update label="September 2026" description="Previews" tags={["Added"]}>
  ### Added

  - [Preview deployments](/docs/deploy/preview-deployments) — unique live URLs
    for each pull request and branch, isolated from production. Available on
    Begin and Value.
</Update>

<Update label="September 2026" description="Code examples" tags={["Added"]}>
  ### Added

  - Readers can report an issue on a published code example. Those reports
    show up in dashboard Feedback.
</Update>

<Update label="September 2026" description="Private docs" tags={["Added"]}>
  ### Added

  - [Authentication setup](/docs/deploy/authentication-setup) — password,
    workspace, OAuth 2.0, and JWT for private documentation, plus public pages
    and group access
</Update>

<Update label="September 2026" description="API" tags={["Added"]}>

  - [Velu REST API](/docs/api-reference/introduction) — trigger deployments,
    search published docs, and embed Ask AI with an API key
</Update>
