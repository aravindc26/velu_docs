---

Velu pages are Markdown first. Headings, lists, tables, links, and fenced code
blocks all render without any extra syntax. When you need something richer, Velu
ships a small set of components you write inline as tags — no imports, no setup.

Plain Markdown and components mix freely on the same page: write prose as usual,
then drop a `<Callout>` or `<CardGroup>` wherever it helps.
